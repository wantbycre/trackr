# Trackr

> 내가 지원한 회사들을 **칸반으로 관리**하고, 전형 단계별 **전환율·응답 소요일**을 대시보드로 보는 개인 구직 파이프라인 트래커.

포트폴리오·면접 시연용으로 만든 사이드 프로젝트입니다. "열자마자 이해되는 직관적 UI" + "실데이터 130건으로 돌아가는 통계"를 목표로 합니다.

---

## ✨ 핵심 기능

- **칸반 보드** — 관심 → 지원 → 서류 → 코테 → 면접 → 오퍼/탈락. 드래그로 단계 이동(낙관적 업데이트 + 실패 시 롤백).
- **카드 상세** — 회사·직무·JD·연봉·마감일·메모 편집 + 단계 변경 **활동 타임라인**.
- **대시보드** — 지원→오퍼 **전환율 퍼널**, 단계별 평균 체류시간, 주간 지원 추이.
- **실데이터 시드** — 실제 지원한 회사 ~130곳을 CSV로 임포트.

## 🧩 기술 스택

| 영역 | 사용 |
|------|------|
| 프레임워크 | Next.js (App Router) + TypeScript |
| 스타일 | Tailwind CSS + shadcn/ui |
| 데이터 | Supabase (Postgres) |
| 서버 상태 | TanStack Query v5 |
| 드래그앤드롭 | dnd-kit |
| 차트 | recharts |

## 🎯 이 프로젝트로 보여주려는 것

- **서버 상태 설계**: TanStack Query 캐시 키 팩토리 + 낙관적 업데이트/롤백 패턴
- **인터랙션 엔지니어링**: dnd-kit 칸반 드래그와 순서(position) 재계산
- **데이터 시각화**: 이벤트 로그 기반 퍼널·체류시간 집계
- **타입 안전성**: Supabase 스키마 → 생성 TS 타입을 앱 전역에서 사용
- **점진적 아키텍처**: 인증 없이 MVP → Phase 2에서 auth/RLS를 얹는 마이그레이션 전략

## 🗂 데이터 모델 (요약)

- `applications` — 칸반 카드. `stage`(enum) + `position_order`(정렬) + 회사/직무/연봉/마감 등
- `application_events` — 활동 타임라인. `stage` 변경 시 트리거로 자동 기록 → 퍼널·소요일 통계의 원천
- `documents` — (Phase 2) 이력서 등 첨부 파일(Supabase Storage)
